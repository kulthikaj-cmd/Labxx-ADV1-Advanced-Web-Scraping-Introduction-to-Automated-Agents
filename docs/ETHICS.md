# Web Scraping Ethics and Legality

1. **Respect robots.txt.** Check the site's crawler guidance before scraping.
2. **Review Terms of Service.** Do not scrape where automated access is prohibited.
3. **Use rate limits.** Avoid sending too many requests; this project includes a delay between pages.
4. **Identify responsibly.** Do not impersonate other services or try to bypass access controls.
5. **Respect copyright and privacy.** Do not republish copyrighted content or collect personal data without a valid basis.
6. **Stop if blocked.** Do not attempt to bypass CAPTCHAs, IP blocks, or other access restrictions.

This project is intended for educational use on the practice site Books to Scrape.
